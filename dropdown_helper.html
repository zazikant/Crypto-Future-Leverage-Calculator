🎯 Contract Selector Helper

Generate JavaScript code to select any contract from Delta Exchange

📖 How to Use:

  1. Enter your desired contract symbol (e.g., ZORAUSD)
  2. Click "Generate Code"
  3. Copy the generated JavaScript code
  4. Open Delta Exchange website
  5. Press F12 to open Developer Console
  6. Go to the Console tab
  7. Paste the code and press Enter
